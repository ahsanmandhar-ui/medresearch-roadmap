SECTION 2 — NEEDS REVIEW
Search Strategy Translation Tools (e.g., Polyglot Search Translator): The SR-Accelerator tool has undergone URL migrations. While extremely valuable, I have omitted it from this batch until the current stable URL ([https://sr-accelerator.com/](https://sr-accelerator.com/)) and functionality can be strictly verified against recent database syntax updates.

SECTION 3 — DUPLICATES / REJECTED RESOURCES
Sci-Hub / LibGen: Rejected. While practically used by many researchers, as a curriculum designer, linking to shadow libraries violates academic integrity principles for a public educational roadmap.

Generic GitHub Repositories for "PubMed Scraping": Rejected. Many violate NCBI's E-utilities API terms of service. litsearchr was retained because it focuses on strategy generation, not bulk unlicensed scraping.

SECTION 4 — CURRICULUM GAPS
Interactive PICO Builders: There is a lack of high-quality, free, open-source web tools that interactively teach students how to map a PICO question into Boolean logic dynamically. This might be a feature you could build directly into your website's UI for Node 00/03.

SECTION 2 — NEEDS REVIEW
Hosmer-Lemeshow Goodness-of-Fit Test: Marked for needs-review / deprecated. Modern biostatistical consensus (Steyerberg, Harrell, TRIPOD group) advises against relying on p-values from the Hosmer-Lemeshow test for model calibration, as it suffers from arbitrary binning and power dependency on sample size. Smooth calibration curves (pmcalibration, rms) are recommended instead.

SECTION 3 — DUPLICATES / REJECTED RESOURCES
Stepwise Variable Selection Algorithms (Forward/Backward Stepwise step() in R): Excluded from recommended model building tools. Stepwise selection based on p-value cutoffs produces biased coefficient estimates, artificially narrow standard errors, and poor out-of-sample calibration. Penalized regression (Lasso/Ridge) and clinical domain knowledge selection are prioritized.

Unvalidated Automated ML Auto-sklearn Pipelines for Clinical Risk: Excluded for primary prediction model development nodes. Black-box AutoML without calibration curves or decision curve analysis violates TRIPOD guidelines for clinical deployment.

SECTION 4 — CURRICULUM GAPS
Interactive Calibration & DCA Simulator: High demand exists for a browser-based interactive tool allowing students to drag-and-drop predicted vs. observed risk vectors to instantly see how calibration slope, intercept, and decision curves change dynamically.

SECTION 2 — NEEDS REVIEW
res_14_2 (DAGitty): Web-hosted instance at dagitty.net is active, but offline desktop/R package (dagitty in R) should be emphasized for computational pipelines.

res_16_4 (MetaInsight): Hosted on Shinyapps.io (crsu.shinyapps.io/MetaInsight/). While supported by NIHR CRSU, free Shinyapps instances can occasionally reach bandwidth limits.

res_17_4 (Covidence): Subscription-based platform with a free trial tier (1 review / 500 records). Open-source alternatives like ASReview or Rayyan should be offered for independent researchers without institutional subscriptions.

SECTION 3 — DUPLICATES / REJECTED RESOURCES
Legacy Stata mvmeta routines: Replaced by modern, open-source R packages (netmeta and gemtc) for better reproducibility and integration with Markdown/Rmd reporting.

Obsolete RoB 1.0 (2008 Cochrane tool): Explicitly excluded; superseded by domain-specific RoB 2 (RCTs) and ROBINS-I (observational studies).

Excel-based Meta-Analysis templates: Rejected due to risk of cell formula corruption and lack of transparent audit trails compared to scripted R pipelines.

SECTION 4 — CURRICULUM GAPS
Diagnostic Test Accuracy (DTA) Meta-Analysis: Requires dedicated coverage of bivariate random-effects models and Hierarchical Summary Receiver Operating Characteristic (HSROC) curves using mada or lme4.

Individual Participant Data (IPD) Meta-Analysis: One-stage vs. two-stage modeling frameworks for pooled patient-level data.

Automated & Machine-Assisted Systematic Reviews: Machine learning deduplication and active learning prioritization algorithms (e.g., ASReview, DistillerSR).
