# OpenCode — QA

Read STATE first.

Run the gates required by the current slice.

For UI slices also:
- run Playwright smoke;
- check browser console;
- keyboard navigate critical controls;
- test reduced motion;
- test responsive breakpoints.

For content slices:
- validate schemas;
- detect duplicate IDs;
- detect duplicate URLs;
- reject non-HTTPS external URLs;
- ensure no pending resource is exposed publicly.

Do not rewrite production features to hide test failures.
